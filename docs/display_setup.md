# ディスプレイの設定（32 インチ縦置きモニタ）

SUMMON THE UFO は **9:16 の縦画面**で動く（#157）。展示では 32 インチのモニタを縦に置いて、画面いっぱいに映す。

## 1. 推奨する解像度

| モニタ | 縦置きにしたときの解像度 | 1 ドットの大きさ |
|---|---|---|
| フル HD（推奨） | 1080 × 1920 | 3 px |
| 4K | 2160 × 3840 | 6 px |

- ゲームの設計解像度は 720 × 1280。ピクセルアートは 360 × 640 のキャンバスを 2 倍にしたもので、上の 2 つの解像度ではどのドットも同じ大きさの正方形になる（補間なし）。
- 9:16 でない解像度（例: 1200 × 1920、横置きのまま）でも動く。絵は 9:16 のまま真ん中に出て、余った所は帯になる。切れたり、縦横で違う倍率に伸びたりはしない。
- 上の 2 つ以外の倍率（例: 1440 × 2560 = 4 px、900 × 1600 = 2.5 px）では、整数倍でないとドットの太さが少し不ぞろいになる。**整数倍になる解像度を選ぶ**。

## 2. モニタを回す（OS 側）

モニタの回転は OS の設定で行う。**ゲームの中では画面を回さない**（回した絵を作らない）。

### macOS

1. モニタをつなぎ、縦に置く（スタンドかアームで 90° 回す）。
2. システム設定 → ディスプレイ → 展示用のモニタを選ぶ。
3. 「回転」を **90°**（モニタを回した向きによっては 270°）にする。「回転」が出ないモニタは、Option キーを押しながら「ディスプレイ」を開くと出ることがある。
4. 「解像度」は「サイズ調整」で **1080 × 1920**（4K のモニタなら 2160 × 3840 か、HiDPI の「1080 × 1920 相当」）にする。
5. 2 台つないでいるときは「配置」で、展示用のモニタをメインにするか、ゲームのウィンドウをそのモニタへ動かしてからフルスクリーンにする。

### Windows

1. デスクトップを右クリック → ディスプレイ設定 → 展示用のモニタを選ぶ。
2. 「画面の向き」を **縦**（モニタを回した向きによっては「縦（反対向き）」）にする。
3. 「ディスプレイの解像度」を **1080 × 1920**（4K なら 2160 × 3840）、「拡大縮小」を **100 %** にする。

### Linux（X11）

```bash
xrandr --output HDMI-1 --rotate left --mode 1920x1080   # 出力名は xrandr で確かめる。逆向きなら --rotate right
```

## 3. フルスクリーンで起動する

次のどれでもよい。

- 起動の引数: `./start.sh --game-only -- --fullscreen`（`--` の後ろがゲームへの引数。実機とつなぐときも同じく `-- --fullscreen` を付ける）。
- 設定画面（タイトルの歯車）→「画面と音」→「フルスクリーン」をオンにして保存。次からは引数なしでフルスクリーンになる（`config/local_settings.json` の `render.fullscreen`）。
- 動いている間に **F11** を押す（フルスクリーン ⇔ ウィンドウ）。
- ウィンドウに戻して起動したいときは `-- --windowed`。

フルスクリーンは、ウィンドウがあるモニタで全画面になる。展示用のモニタがメインでないときは、先にウィンドウをそのモニタへ動かしてから F11 を押す。

## 4. 開発機で見るとき

- 引数なしで起動すると 540 × 960 のウィンドウになる（ノート PC の画面に収まる大きさ。1 ドットは 1.5 px なので、線の太さは少し不ぞろいに見える）。
- 展示と同じドットで見たいときは `--resolution 720x1280`（1 ドット 2 px）か、縦置きのモニタでフルスクリーンにする。

```bash
# 模擬の Dial でスコアゲームを自動で回して、縦画面を確かめる
godot --path game --resolution 720x1280 -- --game-mode --game-mode-devices mock --game-mode-demo --game-mode-seconds 20
```

## 5. 確かめること（展示の前）

- [ ] 画面の四隅まで絵が出ていて、SCORE・TIME・下の Dial 1 / Dial 2 が切れていない。
- [ ] ドットがどれも同じ大きさの正方形に見える（斜めの線がガタガタにそろっている）。ぼやけていたら、解像度が整数倍になっていないか、OS の拡大縮小が 100 % でない。
- [ ] 画面の **左下が Dial 1、右下が Dial 2** で、実機の Dial も左が 1 号機、右が 2 号機になっている（逆なら、モニタの回転が 180° 違う）。
- [ ] 数歩離れて、SCORE と TIME が読める。
- [ ] Space（停止）と Esc（タイトル）が効く。

画面の回転や解像度は**表示だけ**の設定で、ロボットの座標・動く向き・可動範囲・停止、Dial との通信には関係しない。

## 6. まだ確かめていないこと

- 実物の 32 インチ縦置きモニタでの表示（開発機のウィンドウでしか見ていない）。
- 1080 × 1920・2160 × 3840 の実解像度でのドットのそろい方（計算上は 3 px・6 px）。
- 離れた位置からの文字の読みやすさ、Windows / Linux での回転とフルスクリーン。
