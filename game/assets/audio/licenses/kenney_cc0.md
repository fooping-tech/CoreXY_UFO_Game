# Kenney の音源（CC0）

`game/assets/audio/sfx/` の音は、Kenney（https://kenney.nl ）の次のパックのものです。

| パック | ページ | ライセンスの表記（2026-11-16 に確認） |
|---|---|---|
| Interface Sounds | https://kenney.nl/assets/interface-sounds | Creative Commons CC0 |
| Digital Audio | https://kenney.nl/assets/digital-audio | Creative Commons CC0 |
| Sci-fi Sounds | https://kenney.nl/assets/sci-fi-sounds | Creative Commons CC0 |
| Music Jingles | https://kenney.nl/assets/music-jingles | Creative Commons CC0 |

CC0 1.0 Universal（パブリックドメインへの提供）: https://creativecommons.org/publicdomain/zero/1.0/

- 商用・改変・再配布ができ、クレジット表記は不要です（このゲームでは感謝を込めて出典を記録しています）。
- どのファイルをどの音に使っているか、入手元、SHA-256 は `../manifest.json` と `docs/audio_sources.md` にあります。
- ファイルは変更していません（名前も元のまま）。

同じフォルダの上の階層にある mp3（効果音ラボ）は別の規約です。`../SOURCES.md` を見てください。
